# 企业蓝前端设计约定

设计依据为 `docs/design/timesheet_design_system_v1/CODEX_HANDOFF.md` 与 `DESIGN_SYSTEM.md`。这是面向员工和负责人的企业工作台，采用浅色、企业蓝、小圆角和中等信息密度；现有业务规则、权限与真实数据优先于设计示意图。

## 主题与组件接入

- `apps/shared/tokens.css` 同步设计包的 `styles/tokens.css`，仅包含颜色、字体、尺寸、间距等视觉值。修改设计 Token 时同步两份文件；不在其中定义应填时数、步长、红标阈值或审批规则。
- `apps/shared/theme.css` 把 `--ts-*` 映射为 Element Plus 2.14.5 的 `--el-*` 与 Vant 4.10.2 的 `--van-*`。两端 `main.ts` 在组件库 CSS 之后加载主题；全局弹层也使用同一主题。
- 主蓝 `#1664FF`、页面底 `#F5F7FA`、白色卡片、控件 6px、卡片 8px、弹窗 12px；绿色只表示成功，待分配类别保持中性，人员负荷保留原有蓝绿黄红区间。
- `apps/shared/workflow.css` 统一现有原生审批、通知、报表表单与弹窗；基础筛选使用低优先级 `:where()`，排除组件库控件，避免压过主按钮与库主题。
- 保留系统字体、Vue 3、Vant、Element Plus 及已有图标。未增加依赖、远程字体、CDN 或演示 HTML 页面。

## 页面与流程

桌面采用 56px 浅色顶栏、200px 白色侧栏，按原权限表达式显示菜单，填报区域最大 1120px。小屏管理端沿用可横向滚动的文字导航，H5 保留“我的工时 / 审批与协调 / 通知”三项顶部导航。报表横向滚动限制在表格容器。

填报顺序为标题、自然周、当日概览、独立现场日、原位编辑记录、操作栏。应填 / 已说明 / 尚差与项目工作 / 非项目工作 / 待分配 / 请假分别展示，实际工作仅作为汇总说明。分类从当前条目和真实目录得到；历史对象缺失时标记待确认分类，不猜测其类别。请假不重复计入已说明，应填基数为零时不显示比例进度。

复用既有 `SubmissionPanel` 与 `ModalShell`，没有另建一套业务组件树。`SubmissionPanel` 的 `save-status`、`save-action` 插槽容纳两端原保存反馈与按钮；`onsite-target` 使用 Vue 现有 Teleport 将独立现场送审入口放到现场卡片，仍调用原方法。保存为次按钮，预览自然周送审为主按钮。现场送审仍独立，待审批和已处理项不重复提交。

手机底栏预留内容空间和安全区。视口高度不足 500px 时操作栏回到文档流；不会在输入失焦时切换位置，避免点击保存时按钮移动。实际企微容器的虚拟键盘、返回和免登仍需真机验证。

草稿、审批、月份约束与保存反馈分别呈现。可编辑、忙态、冲突、跨日期更正及封账权限继续使用原控制条件。没有增加自动保存、撤回、补造工时或新的成本权限。

## 适用技能

继续参考用户指定的 design-taste-frontend，采用“已审计的视觉改版”，`DESIGN_VARIANCE=3`、`MOTION_INTENSITY=1`、`VISUAL_DENSITY=5`。该技能的营销页布局规则不适用于本后台；保留系统的表单、数据表、语义状态和用户指定技术栈。按 ponytail 原则复用现有组件，只增加共享主题、操作栏呈现和必要展示计算。

验收与截图见 `docs/development/企业蓝视觉改造验收.md`。浏览器展示回归与本地真实接口只读验证分别记录，不将它们表述为真实企微端验收。
