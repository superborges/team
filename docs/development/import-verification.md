## 验证边界与保留数据

本次集成测试在本地种子库保留了带“本地导入验证”名称的测试人员、项目、未来费率版本、导入批次、来源版本和审计，用于检查重复执行与历史事实。没有把这些资料写入生产环境。错误行原规范化值保存在 MySQL JSON；元数据接收与业务应用分开，业务失败不会把接收到的材料抹掉。

此处验证的是服务层、XLSX 解析与真实数据库事务。浏览器 multipart 上传、模板下载及 P10 页面 PARTIAL 显示由最终 API 重启后的页面联调单独确认；本记录不把尚未执行的界面步骤算作通过。未进行 500 行性能压测、外部 OA 契约联调、企业文件样本兼容性测试或全套恶意压缩包评估。

用户 / 组织批量导入、OA 自动同步及来源期间覆盖管理仍未实现。闭账差异目前保留为失败行 / 来源状态，后续月度授权更正流程交付前不能把它当作已处理差异。接口字段和文件约束见 [导入接口约定](import-api.md)。
