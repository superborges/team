# MVP 本地开发验收

更新：2026-09-05。范围依据已批准的 MVP 产品设计和实施计划，沿用用户“先本地验证”的选择。本文替代首批交付文档中的当前进度描述；旧文档保留作为历史记录。

## 交付范围

本地业务使用真实 MySQL / Redis，双端共用后端。测试员工、费率、项目和导入材料均标明测试用途。当前验证不使用真实公司 SSO / OA，也未把本地收件箱标成企微投递成功。

| 页面 / 能力 | 本地实现 |
|---|---|
| P01 我的工时 | 日草稿、自然周、工作/交通/待分配、独立现场、结构复制、保存版本、日级校验、送审预览、更正/取消与重新提交 |
| P02 审批与协调 | 按对象分包、实际接收人、逐项处理、本人回避、公司指定、部分驳回、转交、原处理人核实更正、争议协调与升级 |
| P03–P05 管理分析 | 人员负荷及履约、项目投入及成本、现场台账及占比；三视图承载五能力，支持实时与正式版、筛选和异步 Excel |
| P06 月报修订 | V1 共同截点冻结、重复封账幂等、精确授权、跨月逐项控制、修订差异预览、V2 与旧版保留、例外范围关闭 |
| P07 人员组织 | 稳定内部 ID、字符串工号、换号、生效历史、正副职多人任职、独立授权、批量人员/负责人调整预览及并发核对 |
| P08 归集对象 | 管理员项目维护、部门负责人范围内非项目维护、部门待分配预置、默认路由、关闭后保留历史、来源只读、显式来源关联保留原对象 |
| P09 标准 | 职级与现场标准、生效区间、逐项快照、缺标准阻断；有权角色只读，管理员追加版本 |
| P10 数据接入 | 六类 XLSX 模板、预览、逐行应用、失败文件、重试、来源版本/撤销、请假基数、覆盖核实、现场比对、项目冲突关联 |
| P11 规则与运行 | 参数生效版本、固定规则、自动送审/封账、任务租约/接管/重试、本地通知、审计、日历与全体受影响人员的 BASE 授权检查 |

人员批量部门/职级调整使用已发生的生效日；任职和标准支持未来生效区间。新建部门自动预置待分配对象；local V1002 仅为旧开发部门补齐缺失对象，不覆盖已配置对象。员工的当前资料不会覆盖已发布月报中的历史展示值。不同查询、授权或主数据变更都不能直接把草稿计为确认成本。
