执行方式：

```bash

```

串行脚本防止多个开发任务同时改写 Maven `target/`。导出单测在同一事务内创建请求并推迟其队列任务，防止实际worker与测试生成器争抢；测试月份先设未来截止，需要封账时在测试事务内推进到期。测试只在明确 `WORKLOG_INTEGRATION=true` 且种子管理员确认为 `local-admin` 的环境执行，保留验证记录与审计；未删除业务库或数据库卷。

## 发现并修复

- 并发封账原先先做 `INSERT IGNORE` 再升级到月份排他锁，两个已有月份请求可能各持共享唯一键锁后形成升级死锁。改为原子 upsert 直接取得排他锁；并发测试已通过。
- 合规不能因为某人期间提交过任意一天就排除其他未提交日。现在按到期人日的缺填、草稿和驳回状态去重；每轮审批截止独立保存与统计。
- 已有 day_record / 自动默认日历缓存不能压过发生日生效参数；人工日历仍优先。
- 旧来源失败不能被后续尚未应用的 RECEIVED 记录清除。
- 月份锁后锁定授权人的用户行并重查权限；授权目标项目也锁定后重查。转交审批动作 `TRANSFER` 可被精确授权；授权不能代替业务审批权限或本人回避。
- 最近导出按真实数值主键降序，避免 `CAST(id AS CHAR)` 别名按字符串排序。
- 部分处理后转交剩余项时，正式APPROVAL快照的已处理项使用实际 `handled_by` 及其姓名，待处理项才使用当前包接收人；相应快照断言已通过。

## 实现边界

所有正式快照由同一事务内的一条 SQL 同时保存事实、标签和截点。旧版内容不依赖实时维表；访问仍按当前授权重查。导出文件置于私有目录，申请/生成/下载分别检查权限，文件默认7天有效，清理保留数据库任务与审计。

这里验证的是本地业务实现，没有访问企微/OA真实网络，没有验证真实SSO、外部来源完整率、生产消息投递、真实生产权限配置或生产容量。恢复演练与不含种子的独立迁移检查另见 `本地恢复演练.md`。
