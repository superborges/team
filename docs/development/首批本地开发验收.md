## 可体验的内容

- [电脑端](http://127.0.0.1:5175/admin/)与[手机布局](http://127.0.0.1:5174/h5/)：登录本地测试员工 `98123`，按自然周查看每日草稿，保存项目工作、交通、非项目工作、待分配与独立现场记录。
- 工时与现场分别保存版本，允许只有现场、没有工时；复制只带工作结构，不复制内容或生成现场。保存冲突和校验失败保留输入，保存期间阻止会使输入错位的切换操作。
- 本地管理员 `00123`：维护人员、组织、归集对象、历史费率与工作日历，使用项目、费率、请假三类 XLSX 模板预览及应用数据，查看失败行。
- 内部人员 ID 不随工号变化；支持 `98123`、`XX12345`、`ZD23412` 和含前导零的 `00123`。员工接口不返回费率或金额。
- MySQL 保存业务事实、来源与审计，Redis 保存会话；刷新与跨端读回访问同一后端。数据不是浏览器假数据。

请从模板下载开始体验导入。所有单元格按文本填写，批次中有效行可应用，失败行保留原因；导入成功不表示 OA 来源期间已经完整覆盖。

## 验证记录

本次使用真实 MySQL 8.4 / Redis；没有用 H2 替代 MySQL 的事务、锁和类型行为。2026-09-05 19:16 的最终 `WORKLOG_INTEGRATION=true ./backend/mvnw -B -ntp -f backend/pom.xml verify` 结果为 **32 个测试通过，0 失败、0 错误、0 跳过**，并生成可运行 JAR。该 JAR 已用 `local,api` 启动，健康检查 UP；重启后的 **13 项真实 HTTP / 数据库检查全部通过**。

32 项包括 14 项主数据校验、5 项日规则、5 项计价规则、1 项真实计价查询、4 项 XLSX 解析、1 项导入事务矩阵、1 项登录环境隔离和 1 项 WxJava 客户端装配。集成测试的一个测试方法内包含多个连续业务断言；不把测试方法数量换算为已完成的产品需求数量。原始最终构建输出为 `.local/final-backend-verify.log`。

前端最终类型检查、H5 / Admin 生产构建和 **4 项浏览器回归检查全部通过**。真实浏览器验证已完成两端草稿保存 / 读回、管理员维护，以及 P10 真模板下载 → multipart 上传 → 一行成功一行失败 → PARTIAL → 再次应用不重复新增。浏览器回归中的 HTTP fixtures 与真实后端联调分别记录，不混作真实 SSO 验收。

日历专项真实验证确认：原有 240 分钟请假在休息日的派生值为 `0 / 0 / 0`；改为工作日后从来源重算，数据库与 API 一致为 `480 / 240 / 240`，旧页面版本失效。独立迁移检查库已执行 V1–V4，重跑无待执行迁移，人员表为 0 行，确认没有加载本地身份种子。
