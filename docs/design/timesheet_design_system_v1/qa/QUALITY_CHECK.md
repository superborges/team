# 设计包检查记录

## 范围

检查对象仅为本包 `preview.html`、Token 与参考样式。没有连接真实 MVP 仓库、SSO、OA、数据库或审批服务，不代表生产应用验收。

浏览器使用容器中的 Chromium，通过 Playwright 加载自包含 HTML 内容。环境中的浏览器管理策略禁止 `file://` 导航，因此以 `set_content` 载入相同 HTML 字节进行检查；没有发出外部网络请求。

## 布局与交互

页面示例与组件规范均检查了 320、375、390、768、1024、1440px 六种视口宽度：12 组检查均未发现全局横向溢出。记录位于 `browser-checks.json`。

实际执行了初始汇总验算、修改工时后的合计/尚差更新、新增与移除、空值不伪装为零、周预览提示、工时不足时独立打开现场日演示、模拟保存反馈、现场区展开收起、重复 DOM id 检查，以及键盘 Tab 的 2px 焦点轮廓检查。10 项均通过。未记录浏览器控制台错误或未处理脚本错误。

`*-viewport.png` 为固定视口截图。其他 PNG 为相同宽度、扩展画布高度的完整展示截图，目的是让固定操作栏位于长图底部；后者不代表真实手机屏幕高度。
